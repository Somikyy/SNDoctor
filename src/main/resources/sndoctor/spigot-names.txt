# SNDoctor - Spigot-mapped NMS class names.
#
# Format:  SpigotName=MojangName
#
# Why this file exists
# --------------------
# Starting with Minecraft 26.1 Mojang no longer ships obfuscated server jars, and Paper
# fully dropped its internal remapper. A plugin compiled against Spigot-mapped internal
# names will not run on 26.1+ regardless of whether the server is Paper or Spigot.
#
# Every name on the left is a class name that ONLY exists in the Spigot mapping set.
# Names that are identical in both mapping sets (Entity, ItemStack, MinecraftServer,
# Packet, Scoreboard, Chunk, ...) are deliberately absent - they prove nothing.
#
# You can extend this list without rebuilding:
#   plugin mode : plugins/SNDoctor/spigot-names.txt
#   CLI mode    : --names <file>
# Entries in your file are merged on top of these.
