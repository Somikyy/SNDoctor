# SNDoctor - тексты находок, русский.
#
# Формат: ключ=значение, одна строка на текст. Всё после первого '=' - значение,
# включая кавычки, апострофы и знаки препинания: экранировать ничего не нужно.
# Строки, начинающиеся с '#', игнорируются.
#
# Ключи собираются из id правила, который виден в JSON-отчёте и в таблице
# раздела 4 файла docs/SPEC-SNDoctor.md:
#
#   rule.<id>.title   заголовок находки
#   rule.<id>.why     почему это ломается
#   rule.<id>.fix     что с этим делать
#
# Файл лежит внутри jar и переопределяется, без пересборки:
#   режим плагина - plugins/SNDoctor/messages-ru.txt
#   режим CLI     - флаг --messages <файл>
# Переопределять можно частично: указанные ключи заменяют встроенные,
# остальные берутся из jar.
#
# Свой язык - скопируй этот файл, переведи значения и подложи как messages-<код>.txt.
